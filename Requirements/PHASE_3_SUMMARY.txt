USAGE EXAMPLE
=============

from gce.engine import GCEEngine
from gce.controls.quantity_control import MaxOrderQuantity
from gce.controls.price_control import MaxOrderPrice
from gce.cache.order_cache import Order

# Initialize engine
engine = GCEEngine()

# Register controls
engine.register_control("qty_limit", MaxOrderQuantity(limit=1000))
engine.register_control("price_limit", MaxOrderPrice(limit=1000))

# Set context (caches)
context = {
    "instruments": instrument_cache,
    "prices": price_cache,
    "orders": order_cache,
    "positions": position_cache
}
engine.set_context(context)

# Create and validate order
order = Order(
    order_id="ORD001",
    symbol="0700.HK",
    quantity=100,
    price=440.0,
    side="B",
    trader="Waleed",
    account="APAC_EQTY_CASH"
)

# Validate
passed, results = engine.validate_order(order, is_new=True)

# Get summary
summary = engine.get_control_summary(results)
print(f"Status: {summary['status']}")
print(f"Pass Rate: {summary['pass_rate']}")
print(f"Failures: {summary['failures']}")

TESTING INTEGRATION
===================

Controls can be tested independently:
  passed, msg, limit, order_val = control.validate(order, context)

Or through the pipeline:
  passed, results = engine.pipeline.execute_all(order, context)

Or through the engine:
  passed, results = engine.validate_order(order)

PERFORMANCE CONSIDERATIONS
===========================

- Each control execution is timed independently
- Total pipeline time is sum of all control times
- Pipeline can execute controls in order specified
- Stop-on-fail reduces pipeline execution time for rejections
- Context dict is passed to all controls (zero-copy reference)
